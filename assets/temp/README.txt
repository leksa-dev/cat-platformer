Pixel Art Asset Previews
========================

Style selected: pixel art style A, intended tile size 48x48 px.

IMPORTANT:
These files are cropped previews from a generated asset-sheet image.
They are NOT production-ready game assets:
- sprites are not guaranteed to align to a 48x48 grid
- some panels include headings or borders
- transparency has not been reconstructed
- backgrounds are preview crops, not verified seamless parallax layers
- the font panel is a visual reference, not an installable font

Use this pack for visual review only. Production-ready PNG assets should be
recreated/exported as clean individual images with exact dimensions and alpha.
